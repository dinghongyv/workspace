改动报告工作台 — 静态版使用说明
========================================

【这是什么】
一套纯静态的网页应用（HTML + CSS + JavaScript），无需安装、无需联网、无需服务器。
所有功能（Word 解析、Word 生成、PDF 导出、图片压缩标注）都在浏览器内完成，
数据保存在本机浏览器中，不会上传到任何地方。

【怎么用 — 电脑】
方式一（最简单）：双击 index.html，用 Chrome / Edge 浏览器打开即可。
方式二（推荐，体验最佳）：在该文件夹下启动任意静态服务后访问，
  例如安装了 Python 时：  python -m http.server 8080
  然后浏览器访问        http://localhost:8080

【怎么用 — 手机】
方式一：电脑和手机连同一个 Wi-Fi，电脑启动静态服务（见上），
  手机浏览器访问  http://电脑局域网IP:8080
方式二：把整个文件夹放到您公司自己的网站 / 内网服务器 / 任意静态托管
  （Nginx、OSS、GitHub Pages 等均可），手机访问对应网址即可。
方式三：手机浏览器直接打开本地文件（部分安卓文件管理器支持用浏览器打开 HTML）。

提示：手机上可先打开网址，再点浏览器菜单中的「添加到主屏幕」，
之后即可像普通 App 一样从桌面图标打开。

【标题格式】
产品信息分为「新品号」和「SPU」两个字段：
  标题自动生成：【报告类型】新品号#SPU 材质颜色-[渠道]产品名称 改动报告 日期
  例如：【样品改动】M250298-5#Y12BT0168 山毛榉原木色-[天猫]子母床 改动报告 2026-9-19
  多个 SPU 请在 SPU 框中用短横线连接，如 Y12BT0168-Y12BT0169。

【拍照 / 选图】
上海看样改动中每条改动下方提供两个按钮：
  「选图」—— 从相册选择图片（可一次选多张）
  「拍照」—— 直接调用手机/平板相机拍摄

【导出 Word 版式】
合并导出后生成一份 Word 文档，整体按以下版式输出为表格：
  左侧列：上海评审 / 山东技术评审 / 部门 / 日期 等标签
  右侧列：对应的具体改动内容、图片及图注
  底部行：部门 + 日期

【重要提示】
1. 请保持 index.html、css/、js/、vendor/ 的相对结构不变，
   缺少 vendor/ 下的两个库文件将无法解析/生成 Word。
2. 草稿数据保存在浏览器本地存储中：换浏览器、清缓存会丢失，请及时导出 Word 存档。
3. 建议使用较新的 Chrome、Edge 或 Safari 浏览器。
4. 导出 PDF：在打印窗口中选择「另存为 PDF」，并勾选「背景图形」、选择「彩色」，
   否则导出的 PDF 会丢失颜色。
5. 更新版本后手机上若出现「按钮点了没反应」，是浏览器缓存了旧版文件：
   先看页面右上角版本号，然后强制刷新（下拉刷新不行就在浏览器菜单里
   选「刷新」/「清除缓存」后重新打开）。版本号与最新发布版本一致即正常。
   当前版本：v13。

【文件结构】
index.html            主页面
css/style.css         样式
js/app.js             全部业务逻辑
vendor/               离线依赖库（Word 解析与生成）
manifest.webmanifest  PWA 配置（可选，不影响使用）
